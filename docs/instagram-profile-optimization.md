# Otimização do Instagram — @tech_santos_br

Objetivo principal: transformar visitas ao perfil em inscrições nas três aulas gratuitas de Power BI, sem deixar o perfil com aparência de catálogo de anúncios.

## 1. Perfil

**Campo Nome**

`TECH SANTOS BR | Power BI e Excel`

O campo Nome deve conter os temas pesquisáveis. O nome de usuário permanece `@tech_santos_br`.

**Bio final**

```text
Power BI e Excel sem enrolação
Instrutor certificado Microsoft
+50 projetos entregues
↓ Assista 3 aulas grátis
```

**Categoria sugerida:** Educação ou Consultor de negócios.

**Botões de contato:** manter e-mail e WhatsApp comerciais visíveis, se estiverem atualizados.

**Link único da bio**

`https://techsantos.com.br/aula-gratis.php?utm_source=instagram&utm_medium=organic_social&utm_campaign=curso_power_bi&utm_content=bio`

O texto do botão/link deve ser `3 aulas grátis de Power BI`.

## 2. Destaques

Usar capas simples, com fundo da marca, um único ícone e no máximo uma palavra. Ordem da esquerda para a direita:

### Comece

1. Quem é Clariston e o que a TECH SANTOS BR ensina.
2. Para quem são os conteúdos de Power BI e Excel.
3. O resultado prometido: sair do processo manual para análises profissionais.
4. CTA: `Comece pelas 3 aulas grátis — toque no link da bio.`

### Aulas

1. Apresentar as três aulas gratuitas.
2. Mostrar brevemente o que a pessoa aprenderá.
3. Explicar que o acesso é liberado após o cadastro.
4. Inserir adesivo de link com a URL de Stories registrada em `docs/links-campanhas.md`.

### Alunos

1. Avaliação de Thamirys.
2. Avaliação de Leandro.
3. Avaliação de Joice.
4. Fechamento: `5,0 estrelas · 46 avaliações reais na Superprof`.

Usar somente depoimentos e números que continuem verificáveis na data da publicação.

### Projetos

1. Mostrar um dashboard real sem dados confidenciais.
2. Explicar em uma frase qual problema foi resolvido.
3. Mostrar o antes e depois do processo.
4. CTA para orçamento pelo WhatsApp.

### Curso

1. Para quem é o curso.
2. Conteúdo: modelagem, Power Query, DAX e dashboards.
3. Formato: 13 módulos, 46 videoaulas, acesso vitalício e certificado.
4. CTA: assistir primeiro às aulas gratuitas.

Confirmar módulos, aulas, preço e condições no site antes de republicar.

### Dúvidas

Responder em Stories separados:

- Preciso saber Power BI antes?
- O acesso é vitalício?
- Tem certificado?
- Posso assistir pelo celular?
- Como funciona a garantia?
- Como acesso as aulas gratuitas?

## 5. Ordem de aplicação

1. Alterar o campo Nome, a bio e o link.
2. Fixar os três conteúdos na ordem visual desejada.
3. Publicar a sequência de Stories de ativação.
4. Montar os seis destaques usando Stories já publicados e atualizados.
5. Após sete dias, comparar visitas ao perfil, cliques no link e cadastros originados do Instagram.

## 6. Critério de sucesso

O perfil deve ser avaliado pelo funil completo, não apenas por curtidas:

`alcance → visitas ao perfil → cliques na bio → cadastro nas aulas → compra`

O primeiro diagnóstico deve acontecer após sete dias; a comparação mais confiável, após 28 dias.
